# xiaohei-behemoth-creature-prompt · 巨兽异兽提示词

中英双语提示词生成技能：为巨兽 / 异兽（kaiju, behemoth, titan, colossal creature, monster）
生成具有强烈视觉冲击与史诗感的**图片提示词**与**视频提示词**。支持增强、改写、诊断、扩展已有提示词。

## 核心能力

- **图片提示词**：六维度模块化组装（体型比例 / 形态特征 / 光影氛围 / 动态姿态 / 环境背景 / 色彩风格）
  + 9 层面描写最低标准 + 面向镜头压迫感构图 + 宏大建筑场景
- **视频提示词**：五步法（镜头运动 → 外观动作 → 体量 → 光影 → 镜头特效），顺序锁死，
  专做异兽出场的震撼感，适配图生视频
- **中英双语模板**：适配即梦 / 可灵 / 通义万相 / Midjourney / Stable Diffusion / Flux

## 快速上手

1. 说明要生成什么异兽：**原型 + 氛围**（如「熔岩巨虎，狂暴毁灭」「深渊巨鲨，克苏鲁恐惧」）
2. 图片提示词：打开 `references/image-prompt-library.md`，按六维度各选片段，按组装公式拼接
3. 视频提示词（图生视频）：打开 `references/video-prompt-library.md`，按五步法顺序逐段书写
4. 典型工作流：先用六维度生成一张**面向镜头**的静态图，再用五步法扩写成视频提示词喂给图生视频工具

## 一句话原则

图片九层面管「长什么样」，视频五步管「怎么动、怎么震」；
面向镜头 + 宏大建筑参照 + 底部渺小人群同框，压迫感自然递增。
