# 巨兽异兽提示词编写（Behemoth Creature Prompt）

## Overview

编写「视觉震撼、史诗感强」的巨兽/异兽生图提示词。核心方法是**六维度模块化组装**：
不写一句式长句，而是从六个维度各自选取模板片段，按固定公式拼接，再参数化定制。

六维度概览（详见 `references/image-prompt-library.md` 图片模板库）：
1. **体型与比例** — 用参照物对比衬托体积（山岳、城市、云层、人类）
2. **形态与特征** — 独特生理结构 + 鳞片/毛发/甲壳的微观纹理
3. **光影与氛围** — 逆光、闪电、熔岩、浓雾营造压迫感与史诗感
4. **动态与姿态** — 咆哮、扑击、腾空、吐息等张力动作
5. **环境与背景** — 山川崩裂、风暴肆虐等宏大场景
6. **色彩与风格** — 色调倾向 + 艺术风格统一视觉基调

另有三大强化模块（详见下文与两个模板库）：
- **面向镜头压迫感构图**：正对镜头 + 直视观者 + 低角度仰拍，图生视频首选
- **宏大建筑场景**：城市级巨型遗迹做参照，建筑群比自然景观更能衬托体积
- **视频提示词五步法**：镜头运动→外观动作→体量→光影→镜头特效，顺序锁死，专为图生视频设计

## 使用流程（Workflow）

### Step 1：解析需求
向用户确认（或从描述中提取）：
- **生物原型**：龙、蛇、章鱼、鲸、蜥蜴、昆虫、机械，或「牛头+蛇身」式混合体？
- **情绪基调**：恐惧压抑 / 神圣威严 / 狂暴毁灭 / 远古苍凉 / 神秘未知？
- **目标工具**：中文模型（即梦、可灵、通义万相）→ 用中文片段；国际模型（Midjourney、SD、Flux）→ 用英文片段。
- **特殊要求**：构图（竖幅海报/横幅）、是否要特写、画面风格偏好。

### Step 2：选取模板片段
打开 `references/image-prompt-library.md`，按六个维度各挑选 **1–3 个** 片段：
- 维度 1（体型）必选 1 个参照物锚点，否则「巨」不成立。
- 维度 2（形态）至少选 1 个结构特征 + 建议加 1 个纹理强化。
- 维度 3（光影）选 1 个主光源，可加 1 个氛围元素。
- 维度 4（动态）选 1 个主动作；如需静态威慑可改为「凝视/低伏」。
- 维度 5（环境）选 1 个场景，可与维度 4 动作形成因果（如「扑击 + 城市废墟」）。**宏大优先**：场景尽量选城市级巨型建筑群（环形圣殿 / 金字塔群 / 巨型城墙 / 沉没巨城 / 塔楼群），建筑比山川更能直接衬托体积——「建筑越大，巨兽显得越大」。
- 维度 6（色彩风格）选 1 个色调 + 1 个艺术风格 + 质量后缀。

### Step 3：组装（组装公式）

```
完整提示词 = 主体定义 + [维度1] + [维度2] + [维度3] + [维度4] + [维度5] + [维度6]
```

- **主体定义**放最前：`一只[数量]条[原型]的[形容词]巨兽` / `a [adjective] [creature] with [prototype] features`。
- 片段按「整体 → 细节 → 光 → 动 → 景 → 风格」排序，符合生图模型理解顺序。
- 总长度建议：英文 60–120 词；中文 80–200 字。太长稀释注意力，太短缺乏细节。
- 主体名词在多个片段中重复出现时，可精简为代词或省略。

### 场景贴合（Scene Binding，必做步骤）

**场景必须与巨兽动作形成因果绑定**——环境是巨兽行为的直接结果，不是贴图背景。
组装维度 4（动态）与维度 5（环境）时，强制使用 `references/image-prompt-library.md`
「动作→环境反应绑定表」：选动作后，必须在其后追加对应环境反应，二选一以上。
例：选了「吐息」，就必须写「所过之处熔岩凝固成河 / 大地覆满冰霜」，否则视为未完成。

### 面向镜头压迫感构图（Viewer-Facing Composition，视频生成首选）

若提示词将用于**图生视频**（即梦 / 可灵 / Sora 等），必须在维度 4（动态）中选用
「构图朝向」片段（image-prompt-library.md 的 T4.1–T4.5，至少 2 条），并遵守以下规则——**正面朝向镜头的
巨兽，在视频推近或运镜时压迫感才会持续递增**；侧面/背影适合静态图，视频中张力会流失：

- **正对镜头**：`正面朝向镜头，头颅占据画面上半部`，俯瞰一切。
- **直视观者**：`双瞳锁定观者，瞳孔深处倒映[燃烧的城市 | 闪电 | 月影]`——眼睛是视频中情绪传递的焦点。
- **逼近感**：`正迈步向镜头走来，画面底部是仓皇逃离的微小人群`，制造「正在逼近」的空间威胁。
- **低角度仰拍**：`镜头贴地仰视，它的下巴高过天际线`，配合广角畸变放大头部比例。
- **底部同框参照**：建筑/人群放在画面下缘与巨兽同框，视频运动中体积感翻倍。

### 多维度描写最低标准（未达标不交付）

每条提示词必须覆盖以下 **9 个描写层面**，逐项自查：

| # | 层面 | 要求 | 示例 |
|---|---|---|---|
| 1 | 体积参照 | 至少 1 个参照物锚点（山岳/建筑/云层/人类） | 高过三重楼阁 |
| 2 | 材质结构 | 具体材质词（黑曜石/风化青铜/霜壳），忌「可怕」 | 鳞片如湿黑岩 |
| 3 | 纹理细节 | 毛发根根分明 / 鳞片独立高光 | 覆满霜花的鹿角 |
| 4 | 光源与色温 | 单一主光源 + 方向（逆光/顶光/体积光） | 背后火山逆光 |
| 5 | 三色组合 | 主色+辅色+点缀色（见 image-prompt-library.md 三色组合法） | 炭黑+暗血红+焦橙 |
| 6 | 动态动作 | 1 个主动作 + 张力词 | 仰天咆哮 |
| 7 | 场景反应 | 动作对应的环境反应（场景贴合） | 声浪震碎琉璃瓦 |
| 8 | 情绪氛围 | 1 个情绪定调词 | 压抑、毁灭、庄严 |
| 9 | 构图朝向 | 面向镜头/侧身/背影；视频生成必须面向镜头 | 正面朝向镜头，双瞳锁定观者 |

输出前对照此表逐项打勾，缺项必须补写。

### Step 4：参数化与增强
- 替换模板中的 `[____]` 为具体名词（具体 > 抽象，如「黑曜石鳞片」>「深色鳞片」）。
- 加入 1–2 个「意外细节」提升独特性：共生生物、伤痕、异化器官、古符文等。
- 有明确的构图需求时追加：`wide-angle / telephoto / low-angle shot, vertical composition`（低角度仰拍是巨兽标配）。
- **图生视频用途**：必须选用「构图朝向」片段（T4.1–T4.5）至少 2 条，并把微小参照物（人群/建筑）置于画面底部同框。
- 始终附带**负面提示词**（image-prompt-library.md 末尾有通用版）。

### Step 5：输出与迭代
- 向用户输出组装好的完整提示词，中英双语各一条（若用户未指定工具）。
- 附上 5 秒可读的组装说明：标出用了哪些维度片段（如 `[T1.1]+[T2.4]+[T3.3]`）。
- 如用户反馈「不够震撼 / 太乱 / 不够大」，按如下规则迭代：
  - 不够大 → 换更强参照物锚点（城市 → 山岳 → 破云）。
  - 不够震撼 → 加强光影对比与动态（加闪电、加动作残影）。
  - 元素太乱 → 砍掉 1–2 个细节片段，保主体聚焦。
  - 风格不对 → 只换维度 6 的艺术风格片段。
  - 用于视频却没压迫感 → 换「构图朝向」片段（正对镜头 + 直视 + 逼近）+ 低角度 + 底部参照物。

## 视频提示词五步法（图生视频专用）

图片提示词解决「异兽长什么样」，视频提示词解决「异兽怎么动、怎么震、压迫感怎么递增」。
当用户需要**图生视频**（即梦 / 可灵 / Sora / Runway）时，不走六维度组装，改走五步法——
**顺序锁死，不可调换**，五步叠完震撼感自己长出来。

```
视频提示词 = Step1 镜头运动 + Step2 外观和动作 + Step3 体量 + Step4 光影 + Step5 镜头特效
```

| 步 | 写什么 | 关键 |
|---|---|---|
| 1 镜头运动 | 镜头怎么跟异兽 | 运镜方式 + 与异兽的相对运动 |
| 2 外观和动作 | 形态外观 + 动作时序 | 必须带时序（停留几秒 / 缓缓 / 猛然） |
| 3 体量 | 环境物理反馈 | 地面下陷 / 建筑震颤 / 水面隆起 |
| 4 光影 | 环境光影反应 | 热浪扭曲 / 光雾涌动 / 阴影游移 |
| 5 镜头特效 | 节奏控制 | 日常流畅 + 关键瞬间定格 / 震动 |

**与图片提示词的衔接**：图片九层面（材质 / 纹理 / 光源 / 三色组合）是 Step 2「外观」的素材库。
典型工作流——先用六维度生成一张「面向镜头」的静态图，再用五步法把它扩写成视频提示词喂给图生视频。

详细片段库（V1.1–V5.5）与完全体示例见 `references/video-prompt-library.md`。

**顺序不能乱的原理**：镜头先定位观众视角 → 外观动作让观众认识异兽 → 体量让观众感受「重」
→ 光影让世界被异兽改变 → 镜头特效在关键瞬间踩一脚油门。跳步或乱序，震撼感就会断层。

## 完整示例（多维度全开 + 场景贴合）

### 示例 A：焚天熔龙（狂暴毁灭向，英文，适配 Midjourney）

```
a colossal draconic behemoth as massive as a mountain range, obsidian scales glowing
with crimson embers, bone spikes jutting from spine and shoulders, wings fully spread,
unleashing devastating dragonfire breath that hardens into rivers of lava in its wake,
rear legs braced as the shockwave flattens a ruined city block by block, volcano
erupting on the horizon, lava flooding the streets, palette of charred black, dark
blood red and burning orange, epic fantasy movie still, wide-angle low-angle shot,
cinematic rim lighting, 8k, ultra-detailed
--no low quality, blurry, deformed anatomy, watermark, text, oversaturated
```

### 示例 B：深渊利维坦（神秘深海向，中文，适配即梦/可灵）

```
一只自深渊浮出的巨鲸异兽，海面隆起成海啸，漩涡吞没远方船影；
数十条墨色触须垂落，末梢泛着幽蓝生物光；惨白月光勾勒森然轮廓，
浓雾在它脚下翻涌；它缓缓张开巨口，寒潮自齿缝涌出，飞鸟成群坠落；
极地冰缝向四方崩裂，冷气升腾；主色深海藏蓝，辅色湿炭黑，
点缀冷青荧光，克苏鲁暗黑奇幻风格，低角度仰拍，明暗比 1:8；
8k 超高清，PBR 材质。
负面：低质量，模糊，解剖结构错误，水印，文字，过饱和，构图平淡。
```

## 质量检查清单（出图前自查）

- [ ] 主体定义是否出现在提示词开头？
- [ ] 是否有至少一个「体积参照物」（维度 1）？没有则补。
- [ ] 形态特征是否足够具体（材质、结构、数量）？避免泛泛的「可怕」。
- [ ] 光源是否单一且明确？混光过多会脏。
- [ ] **动作与场景是否因果绑定**（咆哮→震裂、吐息→熔岩河、入水→海啸）？见绑定表。
- [ ] **色彩是否用三色组合**（主色+辅色+点缀色）？避免五颜六色。
- [ ] 是否覆盖「多维度最低标准」8 个层面？逐项打勾。
- [ ] 是否附带负面提示词？
- [ ] 输出是否给出中英双语（或按用户工具选择单语）？
- [ ] **若用于图生视频**：是否满足「正对镜头 + 直视观者 + 低角度仰拍 + 底部参照」四要素？
- [ ] **若生成视频提示词**：五步是否按顺序写全（镜头→外观动作→体量→光影→镜头特效）？Step 2 是否带时序？Step 5 是否有「日常流畅 + 关键瞬间强调」节奏对比？
